## 5. 현재 결과에서 반드시 교정할 사항

현재 보고서는 확률 변화 절댓값으로 순위를 정하면서 양수와 음수를 함께 `판단 근거`로 표현합니다. 의미가 반대이므로 다음처럼 분리하세요.

### 5.1 지지 근거

```text
probability_drop > 0
```

해당 구역을 가렸을 때 원본 예측 클래스의 확률이 감소한 경우입니다. 모델의 원본 판단을 지지하는 정보가 있었을 가능성을 뜻합니다.

### 5.2 억제 근거

```text
probability_drop < 0
```

해당 구역을 가렸을 때 원본 예측 클래스의 확률이 증가한 경우입니다. 원본 클래스의 확신을 낮추는 정보가 있었을 가능성을 뜻합니다.

### 5.3 절대 민감도

```text
absolute_probability_change = abs(probability_drop)
```

방향과 무관하게 모델 출력이 얼마나 민감하게 변했는지를 뜻합니다.

세 순위를 각각 별도 표와 별도 설명으로 표시하세요. 음수 구역을 원본 클래스의 `지지 근거`라고 표현하지 마세요.

## 6. 설명 문구 수정

다음 표현은 사용하지 마세요.

```text
상관관계 기반 설명
이 구역 때문에 MCI로 판단
질환에 중요한 뇌 영역
병변 위치
신경 연결
커넥톰 기반 진단
```

권장 문구:

```text
입력 영상의 각 공간 구역을 인위적으로 마스킹했을 때 발생한 모델 출력의 변화를 측정했습니다. 이 값은 해당 구역에 대한 모델의 출력 민감도를 나타내며, 실제 질병의 원인·병변 또는 해부학적 중요성을 의미하지 않습니다.
```

보고서 제목의 `판단 근거`는 가능하면 다음 중 하나로 변경하세요.

```text
모델 출력 민감도 분석
Graph XAI 설명 결과
모델 예측 변화 분석
```

모델의 예측은 `판단`보다 `예측`으로 표현하세요.

## 9. 설명 안정성 지표

최소 다음을 계산하세요.

### 9.1 마스킹 방식 간 순위 상관

- Spearman rank correlation
- 가능한 경우 Kendall tau

### 9.2 Top-k 일치도

```text
Top-1 overlap
Top-3 Jaccard similarity
```

지지 순위와 절대 민감도 순위를 구분하여 계산하세요.

### 9.3 부호 일치율

같은 구역의 probability drop 부호가 세 마스킹 방식에서 얼마나 일치하는지 계산하세요.

### 9.4 안정성 판정

임계값은 설정 파일로 관리하고, 근거 없이 `안정적`이라고 단정하지 마세요. 기본 판정 예시는 다음과 같습니다.

```text
높음: 평균 Spearman >= 0.70 및 부호 일치율 >= 0.80
보통: 평균 Spearman >= 0.40
낮음: 그 외
```

이 기준은 프로젝트 운영 기준이며 의학적으로 검증된 기준이 아님을 명시하세요.

## 10. CAM-perturbation 일치도

각 이미지와 마스킹 방식별로 다음을 계산하세요.

- CAM 비율과 `probability_drop`의 Spearman 상관
- CAM 비율과 `absolute_probability_change`의 Spearman 상관
- CAM Top-3와 지지 구역 Top-3 overlap
- CAM Top-3와 절대 민감도 Top-3 Jaccard

CAM이 높은데 probability drop이 음수인 경우도 그대로 보존하고 별도로 표시하세요. CAM과 perturbation이 일치하지 않는다고 결과를 삭제하거나 부호를 바꾸지 마세요.

상관계수는 표본이 9개 구역뿐이므로 탐색적 지표임을 명시하세요.

## 11. 다중 샘플 배치 평가

단일 사례 외에 여러 MRI를 평가할 수 있는 배치 실행 기능을 추가하세요.

입력 방식:

- 파일 목록
- 디렉터리
- CSV manifest 중 현재 구조와 가장 안전한 방식

실제 데이터가 있으면 CN/MCI/AD 각각에서 표본을 포함하세요. 데이터가 부족하면 임의 복제하지 말고 실제 사용 가능한 표본 수를 보고하세요.

환자 또는 피험자 정보가 있으면 **동일 피험자의 여러 절편이 평가 집합에 중복되어 독립 표본처럼 집계되지 않도록** 하세요.

배치 결과:

- 전체 이미지 수
- 클래스별 이미지 수
- 가능하면 피험자 수
- 예측 클래스 분포
- 클래스별 지지 구역 빈도
- 클래스별 억제 구역 빈도
- 평균 probability drop과 신뢰구간 또는 분산
- 마스킹 방식별 안정성
- CAM-perturbation 평균 일치도
- 실패·제외 샘플과 이유

추론 성능 평가용 정답 라벨이 존재하면 accuracy, balanced accuracy, Macro-F1, confusion matrix를 계산할 수 있습니다. 정답 라벨이 없으면 분류 성능을 계산하지 마세요.
